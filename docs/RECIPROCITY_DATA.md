# 胶片倒易律失效补偿参考

本文档说明应用使用的倒易律失效（Schwarzschild 效应）补偿模型和各胶片的参数。

> **数据文件**：`src/constants/FilmReciprocity.ts`
> **计算函数**：`src/utils/photographyCalculations.ts` → `applyReciprocityCorrection` / `calculateReciprocity`

## 计算模型

记 `Tm` 为测光时间（已含 ND 滤镜换算），`Tc` 为校正后的实际曝光时间。

### 1. 幂函数模型（power）

```
Tm ≤ T0:  Tc = Tm
Tm > T0:  Tc = T0 · (Tm / T0)^P
```

- `P`：Schwarzschild 指数。P 越大，失效越严重。
- `T0`：开始失效的阈值，默认 1 秒。
- Ilford 官方公式 `Tc = Tm^P` 就是 `T0 = 1` 的情况。

### 2. 厂商数据表模型（table）

Kodak、Fuji、Foma 公布的是离散数据点（例如 Tri-X：1s→2s，10s→50s，100s→1200s）。
应用在 **log-log 坐标**下对这些点做分段线性插值：

```
log Tc = log Tc_i + k · (log Tm − log Tm_i)
k = (log Tc_{i+1} − log Tc_i) / (log Tm_{i+1} − log Tm_i)
```

- 第一个数据点是「无需补偿」的阈值（Tc = Tm），低于它时不做补偿。
- 每一段内部都是幂函数，因此正好穿过厂商给出的每个数据点。
- 超出最后一个数据点后，沿最后一段的斜率外推。

### 可靠范围与外推提示

很多胶片都有 `maxReliableSeconds`（厂商数据覆盖的最长测光时间）。
测光时间超过它时，界面会提示「结果为外推值，建议包围曝光」。

### 与旧模型 (2026.01_calibrated_v1) 的区别

| 问题        | 旧模型                                                                                                                                    | 新模型                                                 |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 倍率上限    | `min(M, maxMultiplier)` 截断，长曝光严重欠曝（例如 Tri-X 100s 只补到 6 倍，官方为 12 倍）                                                 | 不封顶，按数据外推，并提示可靠范围                     |
| 两套数据    | `allfilm.json` 与代码内联参数并存；"Ilford HP5 Plus"、"Kentmere 100/400" 等名称与映射表对不上，未匹配的胶片悄悄退回到另一套互相矛盾的参数 | 每款胶片直接在 `FilmReciprocity.ts` 中定义，单一数据源 |
| Ilford 胶片 | 界面中缺失（只有翻译，没有配置）                                                                                                          | 已加入 Ilford / Kentmere 全系列，使用官方 P 值         |
| 插值        | 线性插值 + 线性外推                                                                                                                       | log-log 插值，与幂函数模型一致                         |
| T1 < 1      | 被 `max(T1, 1)` 强制改成 1                                                                                                                | 支持任意阈值                                           |
| 结果取整    | 校正时间直接 `Math.round`（1.26s → 1s，补偿消失）                                                                                         | 保留精度；短时间显示一位小数，计时器向上取整           |

## 使用建议

**长曝光推荐**：Fuji Acros II（120s 内无需补偿）、Provia 100F（128s 内无需补偿）、T-Max 100。

**谨慎使用**：Fomapan（失效极快）、Velvia 50（易偏色，超过 32s 官方不推荐）。

**注意事项**

1. 倒易律失效受温度、批次、显影影响，参数仅供参考。
2. 关键拍摄建议包围曝光（±1 档）。
3. 彩色胶片长曝光会偏色，厂商通常建议配合 CC 滤镜。
4. Kodak 黑白胶片长曝光时官方还建议缩短显影时间（Tri-X 100s：−30%），本应用只计算曝光时间。

## 添加新胶片

在 `src/constants/FilmReciprocity.ts` 的 `FILM_RECIPROCITY_DATA` 中加一项，
再在 4 个语言文件的 `calculator.exposureLab.reciprocity` 下加上 `<id>` 和 `<id>Description` 两个翻译键。

```ts
{
  id: 'my_film',
  name: 'My Film 400',
  iso: 400,
  type: 'bw',
  model: table([1, 1], stops(10, 1), [100, 400]), // 或 power(1.3)
  source: 'manufacturer',
  maxReliableSeconds: 100,
}
```
